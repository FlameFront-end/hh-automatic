# HH Automatic

Набор небольших скриптов для автоматизации чатов hh.ru.

## Файлы

- `leave-all-chats.js` — находит все доступные чаты, показывает их в консоли и после стандартного подтверждения выходит из каждого.
- `leave-rejected-chats.js` — находит чаты с красным статусом `Отказ` или с сообщением о том, что вакансия уже закрыта, показывает список и после подтверждения выходит только из них.
- `add-resume-skills.js` — добавляет навыки в резюме из массива `SKILLS`, который находится в самом верху файла.
- `remove-resume-skills.js` — удаляет указанные выбранные навыки из резюме после подтверждения.

Оба скрипта используют API `/chatik/api/leave`, поэтому не кликают по меню и модальным окнам.

## Запуск

1. Откройте страницу [hh.ru/chat](https://hh.ru/chat) и убедитесь, что вы авторизованы.
2. Откройте DevTools → Console.
3. Откройте нужный `.js`-файл, скопируйте содержимое и вставьте в консоль.
4. Скрипт сначала соберёт список и выведет его через `console.table()`.
5. Проверьте список и нажмите `ОК` в стандартном окне подтверждения, если всё верно.
6. Скрипты пытаются получить `x-xsrftoken` автоматически из текущей сессии hh.ru. Ручной ввод появляется только как резервный вариант, если автоматическое получение не удалось.

До подтверждения запросы выхода не отправляются. Для `leave-all-chats.js` предусмотрена дополнительная защита: после стандартного подтверждения нужно вручную ввести фразу `ВЫЙТИ ИЗ ВСЕХ`. При отмене или ошибке ввода обработка прекращается.

## Остановка

Для полного скрипта:

```js
stopHHAll()
```

Для скрипта отказов:

```js
stopHHRejects()
```

## Важное замечание

Ответ `/chatik/api/filter_clusters` содержит `vacancyId`, а API выхода требует `chatId`. Эти значения не взаимозаменяемы, поэтому скрипты получают `chatId` из списка чатов в DOM.

Токен `x-xsrftoken` не сохраняется в файлы и не выводится в консоль. Он используется только для запроса hh.ru. Если автоматическое получение не сработает, значение можно взять из Network → Headers у запроса `/chatik/api/leave`.

## Автодобавление навыков

Откройте страницу редактирования резюме с полем Skills, затем откройте DevTools → Console и вставьте содержимое `add-resume-skills.js`.

Список навыков настраивается в первых строках файла:

```js
const SKILLS = [
  "React",
  "TypeScript",
  "Ваш навык"
];
```

Скрипт проверяет уже добавленные навыки и выбирает только точные подсказки hh.ru. После добавления он автоматически нажимает «Сохранить», открывает экран уровней, выбирает уровень для новых навыков и нажимает финальное «Сохранить».

Настройки автоматического выбора уровня находятся сразу под массивом навыков:

```js
const AUTO_FINISH_LEVELS = true;
const DEFAULT_SKILL_LEVEL = "Средний";
const SKILL_LEVELS = {
  "React": "Продвинутый"
};
```

Если навык не указан в `SKILL_LEVELS`, используется `DEFAULT_SKILL_LEVEL`. Допустимые значения: `Базовый`, `Средний`, `Продвинутый`. При `AUTO_FINISH_LEVELS = false` скрипт остановится после добавления навыков и оставит сохранение ручным.

### Удаление навыков

Запускайте `remove-resume-skills.js` на странице редактирования резюме hh.ru, именно на экране «Какими навыками владеете?», как на скриншоте. Не запускайте его на странице списка резюме или в профиле.

Список для удаления находится в самом верху файла:

```js
const SKILLS_TO_REMOVE = [
  "Linux",
  "Docker",
  "Python"
];
```

Для удаления всех выбранных навыков измените настройку в начале файла:

```js
const REMOVE_ALL_SKILLS = true;
```

При `true` скрипт удаляет все выбранные навыки, но не рекомендованные. Для этого режима требуется дополнительное подтверждение фразой `УДАЛИТЬ ВСЕ НАВЫКИ`. Кнопка «Сохранить» не нажимается автоматически — после проверки результата сохраните изменения вручную.
